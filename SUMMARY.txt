📊 BEFORE vs AFTER
───────────────────────────────────────────────────────────────────

BEFORE (Single File Only):
  1. Select one file
  2. See: "photo.jpg" + "4.2 MB"
  3. Send
  4. Response: {"success": true, "filename": "photo.jpg"}

AFTER (Multiple Files):
  1. Select multiple files
  2. See: "5 files selected" + "62.4 MB total"
  3. Send
  4. Response: {"success": true, "saved": ["photo.jpg", "photo (1).jpg", ...]}

CLI OUTPUT:

BEFORE:
  ↓ File received
    Saved: photo.jpg

AFTER (Single):
  ↓ File received
    Saved: photo.jpg

AFTER (Multiple):
  ↓ 5 files received
  
    Saved: photo.jpg
    Saved: photo (1).jpg
    Saved: photo (2).jpg
    Saved: cat.png
    Saved: document.pdf
